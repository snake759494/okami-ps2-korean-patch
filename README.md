# 오오카미 (PS2) 한글패치

PS2 일본판 **大神 (SLPM-66375)** 용 비공식 한국어 패치입니다. 대사·메뉴·도감·아이템 설명·시스템 메시지 전체와 메뉴·타이틀의 글자 그림을 한국어로 바꿨습니다. 현재 배포판은 **v1.0.1 (2026-10-19)** 입니다.

[패치 다운로드](https://github.com/snake759494/okami-ps2-korean-patch/releases/latest) · [기술 설명](docs/TECHNICAL.md) · [재빌드](docs/BUILD.md) · [변경 기록](CHANGELOG.md) · [권리 안내](RIGHTS.md)

릴리즈 첨부 파일은 **Ookami_PS2_KO_v1.0.1.xdelta 하나**입니다. 저장소에는 제작 도구와 기술 문서만 공개합니다. 원본 및 완성 디스크 이미지, 추출한 게임 파일, 글꼴 파일, 외부 실행 파일, 일본어 원문, 번역 대본은 포함하지 않습니다. GitHub 가 자동 생성하는 Source code ZIP/TAR 는 저장소 소스의 압축본이며 게임 파일이 아닙니다.

## 대상 버전

이 패치는 **PS2 일본판 SLPM-66375 의 DVD ISO (2,048 바이트 섹터)** 에만 적용합니다. 파일 이름보다 아래 크기와 해시가 일치하는지가 중요합니다.

| 원본 형식 | 수정되지 않은 일본판 DVD ISO |
| 원본 ISO 크기 | 4,279,599,104 바이트 |
| **원본 ISO MD5** | `ec6dc2c6339af71a6dc7076cf72156e7` |
| 원본 ISO SHA-256 | `b0c55adb2f3d474e108466b52db895c2c92963a0f6bd55f4c1abac2c6ec02e9d` |

## 패치 적용 방법

### Windows 에서 원본 확인

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\Ookami (Japan).iso'
```

위 표와 다르면 적용을 중단하세요. CHD·CSO 등으로 변환한 이미지에는 적용할 수 없습니다.

### xdelta UI 사용

1. 릴리즈에서 `Ookami_PS2_KO_v1.0.1.xdelta` 를 받습니다.
2. xdelta3 패치를 지원하는 도구의 **Apply Patch** 기능을 엽니다.
3. **Patch** 에 xdelta 파일, **Source File** 에 해시가 일치하는 원본 `.iso` 를 선택합니다.
4. **Output File** 에 새 파일명(예: `Ookami (Japan) (Korean).iso`)을 지정합니다.

xdelta 는 호환성을 위해 2차 압축과 파일 경로 헤더 없이 만들었습니다(`-e -9 -S none -A`).

### 명령줄 사용

```powershell
.\xdelta3.exe -d -s '.\Ookami (Japan).iso' '.\Ookami_PS2_KO_v1.0.1.xdelta' '.\Ookami (Japan) (Korean).iso'
```

## 한글화 범위

- 게임 메시지 9,627개: 스토리·마을 대사, 붓 기술 두루마리, 도감(동물·물고기·보물·요괴·전문록), 아이템·장비 설명, 상점, 지도, 퀘스트 제목, 선택지, 시스템 메시지
- 한글 글꼴: 서울한강체 B, 블록별 글꼴 텍스처에 필요한 음절만 배치
- 글자 그림 46종(같은 그림 90곳): 타이틀 메뉴·버튼 안내, 행동 안내(듣기·그리기·점프 등), 아이템 메뉴(장비품·도구·앞/뒤·신장구), 상점, 지도, 상태 화면, 결과 화면, 붓 속성 표찰, 새/완료 표시 등
- 자동 줄바꿈: 원본 창 폭을 넘는 문장은 빌드할 때 단어 단위로 다시 나누고, 대화창은 다음 페이지로 넘김

## 알려진 한계

- **동영상 자막은 넣지 못했습니다.**
- 그대로 둔 글자 그림: 타이틀 로고, 붓 효과 한자, 신·송·죽·매 등급, 도장, 십이지, 붓 기술 이름 띠, 미니게임 설명판, 도감 삽화 속 손글씨, 서브 화면 제목, 타이틀 대기 중 데모 도입부의 단어 그림
- 타이틀 대기 중에 자동 재생되는 데모 플레이는 별도 데이터를 써서 일본어로 나올 수 있습니다(실제 게임 진행에는 영향 없음).
- 줄 수가 원문보다 많아지는 문장은 창 폭 안에서 다시 나누며, 매우 긴 15문장은 창 끝에 붙을 수 있습니다.
- 일부 도감 레코드는 고정 크기 때문에 작은 칸 글꼴을 써서 글씨가 조금 작게 보일 수 있습니다.
